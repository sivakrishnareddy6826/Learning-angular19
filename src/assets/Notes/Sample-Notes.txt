Q: How you implemented pagination in backend .net and how you integrated
We implemented server-side pagination using Skip & Take in EF Core,
returned a paged response with total count, and integrated it in Angular using query params and RxJS with next/previous controls.

Q: Search and pagination
Search is implemented on the server side using query parameters.
Pagination is applied after filtering, so totalCount reflects searched records only.
On the UI, we debounce user input to avoid unnecessary API calls.

Q: Sorting + pagination + search
“We implemented server-side search, sorting, and pagination using query parameters.
Filtering happens first, then sorting, followed by pagination to ensure totalCount is accurate.
On the UI, we debounce search input and reset pagination on sort or search changes.”
